앱 소개

어떤비용은 복잡한 주거 비용을 쉽고 빠르게 계산할 수 있는 모바일 앱입니다. 계산 결과를 저장하고 언제든지 다시 확인하세요.

전세 vs 월세 비교 전세 대출이자와 월세 비용을 비교해요
반전세 계산 전월세 전환율로 월세 적정성을 확인해요
대출이자 계산 월 이자와 총 이자를 빠르게 계산해요
월 고정비 계산 매달 나가는 고정 지출을 한눈에 정리해요
연말정산 세액공제 월세 공제와 전세대출 절세 혜택을 계산해요
DSR/DTI 계산 소득 대비 대출 상환 부담을 확인해요
중개보수 계산 매매·임대차 중개보수 상한을 계산해요
취득세 계산 취득가액과 보유 주택 수로 간이 계산해요

주요 기능

  • 최근계산 탭 — 저장된 계산 내역을 바텀 탭에서 바로 확인 NEW
  • 계산 결과 저장 및 메모 — 계산 후 저장하고 메모를 추가할 수 있어요
  • 즐겨찾기 — 자주 보는 계산을 즐겨찾기로 빠르게 접근해요
  • CSV / PDF 내보내기 — 계산 결과를 파일로 내보내 공유할 수 있어요
  • 생체인증 / PIN 잠금 — Face ID·Touch ID 또는 PIN으로 앱을 보호해요
  • 공지사항 — 앱 내 공지사항을 푸시 알림으로 받아볼 수 있어요
  • 로그인 없이 사용 가능 — 모든 계산 기능은 비로그인으로도 이용 가능해요

자주 묻는 질문

Q. 계산 결과는 정확한가요?

계산 결과는 참고용입니다. 실제 계약 전 전문가에게 확인하시기 바랍니다.

Q. 로그인 없이 사용할 수 있나요?

로그인 없이도 모든 계산 기능을 이용할 수 있습니다. 계산 결과 저장 및 기기 간 동기화는 로그인이 필요합니다.

Q. 개인정보가 저장되나요?

입력한 금액 등 계산 데이터는 기기 내에 저장되며, 로그인 후 저장·동기화 기능을 사용할 경우 계정과 연동되어 서버에 저장될 수 있습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

Q. 생체인증은 어떻게 설정하나요?

설정 화면에서 Face ID / Touch ID 또는 PIN 잠금을 활성화할 수 있습니다.
