1단계 서버 플랫폼, 어떤 걸 선택할까요?

둘 다 무료로 시작할 수 있고, Flutter와 잘 맞아요. 하나를 골라주세요.

🔥 Firebase

Google Firebase

구글이 만든 서비스형 백엔드. Flutter 공식 지원, 한국 개발자 자료 풍부.

✓ Flutter 공식 패키지(FlutterFire) 제공
✓ 한국어 튜토리얼·유튜브 자료 매우 많음
✓ 코드 없이 콘솔에서 DB 직접 확인 가능
✓ 무료 플랜(Spark)으로 충분히 시작 가능
✗ NoSQL 구조 — 복잡한 쿼리 나중에 어려워짐
✗ 구글 서비스에 종속

🎯 빠르게 시작하고 싶은 초보자, 한국어 자료를 많이 참고하고 싶은 분

⚡ Supabase

Supabase

오픈소스 기반의 Firebase 대안. PostgreSQL(진짜 SQL DB) 사용.

✓ PostgreSQL — SQL로 데이터 관리, 나중에 복잡한 기능도 수월
✓ 대시보드가 직관적 — 테이블 뷰로 엑셀처럼 데이터 확인
✓ 무료 플랜 관대함 (프로젝트 2개, 500MB DB)
✓ 4단계 AI 기능에 필요한 벡터 검색 내장 지원
✗ 한국어 자료가 Firebase보다 적음
✗ Flutter SDK 성숙도가 Firebase보다 낮음

🎯 AI·공유 기능까지 계획하는 분, SQL로 데이터를 체계적으로 관리하고 싶은 분

⭐ 내 추천은 Supabase. 이 앱은 4단계(AI)까지 계획하고 있어서 처음부터 SQL DB를 쓰는 게 훨씬 유리해요. Firebase는 초반엔 쉽지만 기능이 늘수록 구조적 한계가 느껴져요.
