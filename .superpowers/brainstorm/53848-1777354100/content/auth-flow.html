섹션 3: 인증 흐름

앱 실행부터 로그인까지, 그리고 기존 데이터 이전까지의 전체 흐름이에요.

📱 앱 실행
옵션 A
👤 로그인 없이 시작
비회원 모드
• Hive 로컬에만 저장
• 모든 기능 사용 가능
• 데이터는 기기에만 존재
나중에 계정 연결 시
Hive 데이터 자동 Supabase 이전 ✓
또는
옵션 B
📧 이메일로 계정 만들기
Step 1
이메일 + 비밀번호 입력
Step 2
인증 이메일 발송 (Supabase 자동)
Step 3
링크 클릭 → 로그인 완료
🔄 최초 로그인 시: 로컬 데이터 자동 이전
Hive 로컬 데이터 → Supabase Cloud (일괄 업로드)
✅ 로그인 이후: 이중 저장 구조
로컬 (Hive)
• 오프라인 즉시 읽기
• 빠른 UI 응답
• 오프라인 신규 입력 가능
⇄
클라우드 (Supabase)
• 온라인 시 자동 동기화
• 다기기 접근
• 데이터 영구 보관
