로그인 방식을 어떻게 할까요?

사용자가 앱에서 어떻게 계정을 만들고 로그인할지 결정해요. 복수 선택 가능.

A

📧 이메일 + 비밀번호

가장 기본적인 방식. 이메일 입력 → 비밀번호 설정 → 이메일 인증. 구현이 가장 단순하고 Supabase에서 기본 제공.

구현 쉬움 Supabase 기본 제공
B

🔵 구글 로그인

버튼 하나로 로그인 완료. 비밀번호 관리 불필요. 한국 앱에서 가장 보편적인 소셜 로그인.

UX 최고 구글 콘솔 설정 필요
C

🟡 카카오 로그인

국내 앱에서 선호도 1위. 카카오 계정으로 원터치 로그인. 단, Supabase와 연동 설정이 다소 복잡함.

국내 사용자 친숙 설정 복잡
D

👤 비회원 모드 지원

로그인 없이도 앱 사용 가능. 나중에 계정 만들면 기존 데이터 이전. 사용자 진입 장벽을 낮추고 싶을 때.

진입장벽 낮음 데이터 이전 로직 필요

⭐ 초보자 추천 조합: A(이메일) + D(비회원 모드). 구현이 단순하고, 사용자도 부담 없이 앱을 먼저 써볼 수 있어요. 나중에 B(구글)는 쉽게 추가 가능.
