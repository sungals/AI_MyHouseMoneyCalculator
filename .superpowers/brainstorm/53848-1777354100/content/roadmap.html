☁️

클라우드 동기화 — 모든 것의 기반

시작점

서버 계정 생성, 로그인/로그아웃, 히스토리 클라우드 저장. 이 단계를 완성하면 나머지 3개가 쉬워져요.

Firebase / Supabase 이메일 로그인 데이터 동기화 난이도: 초급
2
📊

실시간 금융 데이터

한국은행 API 등에서 기준금리·전환율을 자동으로 가져와 앱에 반영. 사용자가 직접 수치를 입력 안 해도 됨.

한국은행 Open API 서버 스케줄러 난이도: 중급
3
👥

공유 / 커뮤니티

계산 결과를 링크 하나로 공유. 지역별 임대 시세 데이터 열람. 1단계 계정 시스템 위에 자연스럽게 추가.

공유 링크 생성 지역 시세 DB 난이도: 중급
4
🤖

AI 분석 / 조언

사용자 데이터 + 시세 데이터를 기반으로 "이 전세금은 이 지역 평균보다 15% 높아요" 같은 맥락 있는 조언 제공.

Claude API 벡터 검색 난이도: 고급

💡 추천: 1단계부터 시작하면 서버 개념을 자연스럽게 익히면서, 이미 쓸 수 있는 기능이 생겨요. 각 단계는 2~4주 정도 예상됩니다.
