섹션 5: 테스트 전략

서버 초보자라면 처음부터 모든 걸 자동화할 필요 없어요. 단계별로 검증 방식을 늘려가요.

먼저 수동 테스트 체크리스트 코드 짠 뒤 직접 확인
이메일 회원가입 → 인증 메일 수신 → 로그인 성공
비회원으로 계산 저장 → 계정 연결 → Supabase에 데이터 이전 확인
비행기 모드 → 계산 입력 → 와이파이 켜기 → 자동 동기화 확인
로그아웃 → 재로그인 → 히스토리 복원 확인
Supabase 대시보드에서 저장된 데이터 직접 눈으로 확인
🧪 단위 테스트 (Unit Test) 기존 테스트 유지

전월세 전환, 대출 이자 등 계산 로직은 서버와 무관하게 계속 테스트.

test('전세 → 월세 전환 계산', () {
  expect(convertToMonthly(100000000, 5.0), equals(416666));
});
🔗 통합 테스트 (Integration Test) 1단계 완성 후 추가
▸ Supabase 테스트 프로젝트 별도 생성 (무료 플랜으로 추가 가능)
▸ 로그인 플로우, 데이터 저장/불러오기 자동화
▸ Flutter integration_test 패키지 활용
📋 초보자 권장 순서
① 수동 체크리스트 → ② 기존 단위 테스트 유지 → ③ 통합 테스트 추가

처음엔 수동 검증으로 충분해요. 기능이 안정되면 자동화를 추가하는 게 훨씬 효율적이에요.
